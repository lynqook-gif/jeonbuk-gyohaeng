🖥️ 서식까지 그대로, 한꺼번에 바꾸기 — PC 일괄 변환 (추천)
  1. (첨부파일_일괄변환.bat)
  2. 받은 파일을 바꿀 파일들(hwp · xls · doc · ppt)과 같은 폴더에 넣기
  3. 더블클릭 → 컴퓨터에 깔린 한글 · 엑셀 · 워드 · 파워포인트가 하나씩 열어 [다른 이름으로 저장]을 대신 해 줘요
  4. 같은 폴더에 hwpx · xlsx · docx · pptx가 생기면 그 파일을 첨부 (원래 파일은 그대로, 결과는 변환결과.txt)
  • 프로그램이 직접 저장하는 것이라 모양이 원래 그대로예요. doc · ppt도 돼요.
  • 한글 · MS 오피스가 설치된 PC에서만 돼요. 파일은 이 PC 밖으로 나가지 않아요.
  • 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]을 누르세요.
  • 한글이 "접근 허용"을 물으면 [모두 허용]을 누르세요.
  • 이미 같은 이름의 새 형식 파일이 있으면 건너뛰어요. 암호가 걸린 파일은 실패로 표시돼요(직접 저장).
  • 학교 PC 보안 설정으로 실행이 막히면 아래 방법대로 직접 저장해 주세요.
📌 첨부 전에 꼭 읽어 주세요
왜 바꿔야 하나요?

문서를 전송할 때 첨부파일 확장자에 따라 보내지지 않을 수 있어요. hwp · xls · doc · ppt 같은 옛 형식은 hwpx · xlsx · docx · pptx로 다시 저장해서 붙여 주세요.

추천 방법 (위에서부터)
  1. PC 일괄 변환(위) 또는 그 프로그램에서 [다른 이름으로 저장](아래) — 모양이 그대로라 가장 정확해요.
  2. 이름만 옛 형식으로 나온 파일 — 이 도구의 [이름 바꿔 받기]. 내용은 그대로예요.
  3. 한글 · 오피스가 없는 PC에서 급할 때만 — 이 도구의 [바로 변환] (xls · hwp). 오른쪽 주의점 확인
⚠️ 바로 변환 주의점
  • hwp → hwpx: 글과 표 내용만 옮겨요. 글꼴 · 글자 크기 · 가운데 정렬 · 줄 간격 · 칸 높이는 기본값이 되고, 그림 · 도형 · 머리말 · 쪽 번호 · 서명 이미지는 빠질 수 있어요.
  • xls → xlsx: 값 · 수식 · 병합은 그대로, 글꼴 · 색 · 테두리 · 인쇄 설정은 빠질 수 있어요.
  • 바꾼 파일은 꼭 열어서 확인한 뒤 첨부하세요. 원래 파일은 그대로 남아요.
  • 암호가 걸린 파일 · 배포용 문서는 바꿀 수 없어요. doc · ppt는 프로그램에서 다시 저장해 주세요.
🛠️ 프로그램에서 다시 저장하는 방법 (서식 그대로)
hwp → hwpx한글
  1. 파일을 한글에서 열기
  2. [파일] → [다른 이름으로 저장하기] (단축키 Alt+V)
  3. 파일 형식에서 *.hwpx(한글 표준 문서) 고르기
  4. [저장]
xls → xlsx엑셀
  1. 파일을 엑셀에서 열기
  2. [파일] → [다른 이름으로 저장] (단축키 F12)
  3. 파일 형식에서 Excel 통합 문서 (*.xlsx) 고르기
  4. [저장]
doc → docx워드
  1. 파일을 워드에서 열기
  2. [파일] → [다른 이름으로 저장] (단축키 F12)
  3. 파일 형식에서 Word 문서 (*.docx) 고르기
  4. [저장]
ppt → pptx파워포인트
  1. 파일을 파워포인트에서 열기
  2. [파일] → [다른 이름으로 저장] (단축키 F12)
  3. 파일 형식에서 PowerPoint 프레젠테이션 (*.pptx) 고르기
  4. [저장]

※ 다시 저장하면 원래 파일(.hwp 등)은 그대로 남고 새 형식 파일이 하나 더 생겨요. 첨부할 때는 새로 생긴 파일을 고르세요.
